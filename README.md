# Marketing Campaign Analysis Dashboard

An interactive dashboard for analyzing marketing campaign performance data. Built with FastAPI, Streamlit, and the Kaggle API.

---

## Project Overview

The dashboard pulls 200,000+ marketing campaign records from the Kaggle API and presents them in an interactive Streamlit interface with dynamic filters, KPI cards, and charts. Every categorical column in the data can be filtered from the sidebar.

### Architecture

```
Streamlit (frontend) → FastAPI (backend) → Kaggle API (data)
```

- The **FastAPI backend** downloads the dataset from the Kaggle API when it starts. No static data files or database are required.
- The **Streamlit frontend** calls the backend to retrieve filtered data and render the visuals.
- The backend is hosted on **Railway** and the frontend on **Streamlit Community Cloud**.

## Getting Started

### Prerequisites
- Python 3.12 or later
- A Kaggle account with API credentials

### 1. Set environment variables
The backend reads your Kaggle credentials from these variables:

```bash
export KAGGLE_USERNAME="your_kaggle_username"
export KAGGLE_KEY="your_kaggle_key"
```

### 2. Install dependencies
```bash
pip install -r backend/requirements.txt
pip install -r frontend/requirements.txt
```

### 3. Start the backend
```bash
cd backend
python3 -m uvicorn main:app --reload
```

The backend downloads the dataset from the Kaggle API on startup.

### 4. Start the frontend
In a second terminal:

```bash
cd frontend
python3 -m streamlit run app.py
```

The frontend connects to a local backend by default. To point it at a different backend, set the `API_BASE` environment variable before starting it.

### 5. Open the dashboard
Streamlit prints the local address in the terminal. Open it in your browser.

## Using the Notebook

`notebooks/eda.ipynb` reads the dataset from a `data/` folder at the project root. That folder is ignored by Git. To use the notebook, download the dataset into it first:

```bash
kaggle datasets download -d manishabhatt22/marketing-campaign-performance-dataset --unzip -p data/
```

## Deployment

### Backend: Railway
1. Connect the GitHub repository to [Railway](https://railway.app).
2. Set the service root directory to `backend`.
3. Add `KAGGLE_USERNAME` and `KAGGLE_KEY` as Railway variables.

### Frontend: Streamlit Community Cloud
1. Connect the GitHub repository to [Streamlit Community Cloud](https://share.streamlit.io).
2. Set the main file path to `frontend/app.py`.
3. In the app's secrets, add `API_BASE` as a top-level key set to the backend's public address. Streamlit exposes top-level secrets to the app as environment variables.

---

## Environment Variables

| Variable | Used by | Description | Where to set |
|---|---|---|---|
| `KAGGLE_USERNAME` | Backend | Your Kaggle username | Shell locally, Railway variables when deployed |
| `KAGGLE_KEY` | Backend | Your Kaggle API key | Shell locally, Railway variables when deployed |
| `API_BASE` | Frontend | Address of the backend | Streamlit secrets when deployed, optional locally |

Credentials are never committed to this repository.
